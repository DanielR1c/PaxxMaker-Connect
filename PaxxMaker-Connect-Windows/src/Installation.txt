PaxxMaker-Connect for Windows
=============================

Install
-------
1. Extract "PaxxMaker-Connect-....zip" completely. Do not run the app from
   inside the ZIP.
2. Double-click "PaxxMaker-Connect Install.cmd".
3. The app is copied to %LocalAppData%\Programs\PaxxMaker-Connect and a
   Start Menu entry is created.
4. Optionally enable the firewall rule and autostart.
5. On the first launch, confirm the SmartScreen prompt with
   More info -> Run anyway, because the file is not signed.
6. Allow access for private networks when Windows Firewall asks.

To uninstall, run "PaxxMaker-Connect Deinstall.cmd".

Requirement: OrcaSlicer
-----------------------
OrcaSlicer has to be installed: https://github.com/OrcaSlicer/OrcaSlicer/releases
Important: start OrcaSlicer once and walk through its setup wizard with your
printer. Only then do print profiles exist – before that PaxxMaker-Connect
reports "No Orca profiles found".
For the Snapmaker U1 OrcaSlicer ships the profiles itself; Snapmaker Orca is
not needed on Windows.

Connect
-------
On the iPhone/iPad in PaxxMaker: Slicer › "Connect with QR code" and scan the
QR code – or "Connect manually" and type the 6-character code.
PC and iPhone must be on the same Wi-Fi/network.
